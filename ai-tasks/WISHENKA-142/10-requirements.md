# WISHENKA-142: Убрать скачок списка при перетаскивании раскрытой карточки

## Goals

Сделать изменение порядка желаний с помощью перетаскивания на сенсорных устройствах предсказуемым и комфортным в ситуации, когда перетаскиваемая карточка предварительно раскрыта.

Сейчас при начале перетаскивания раскрытой карточки её подробности мгновенно скрываются, из-за чего все расположенные ниже карточки резко сдвигаются вверх прямо под пальцем пользователя. Это дезориентирует и делает выбор целевой позиции для первого перемещения непредсказуемым. Задача устраняет этот визуальный и позиционный скачок списка.

## User Stories

- **Как владелец вишлиста на мобильном устройстве**, я хочу перетаскивать раскрытую карточку желания без внезапного сдвига остальных карточек вверх под моим пальцем, чтобы точно видеть, куда именно я перемещаю элемент.
- **Как владелец вишлиста**, я хочу, чтобы при отмене перетаскивания раскрытой карточки она оставалась раскрытой, а список не прыгал ни в начале жеста, ни при его отмене.
- **Как владелец вишлиста**, я хочу, чтобы перетаскивание свёрнутых карточек, прокрутка списка и перетаскивание мышью на десктопе продолжали работать без изменений.

## Definition of Done

1. При начале touch-перетаскивания раскрытой карточки желания карточки списка под ней не сдвигаются вверх (позиция остальных элементов списка остаётся стабильной).
2. Во время перетаскивания раскрытой карточки её содержимое остаётся видимым в приглушённом (полупрозрачном) состоянии, сохраняя исходную высоту карточки без появления пустых разрывов и скачков разметки.
3. При отмене перетаскивания раскрытая карточка остаётся в раскрытом состоянии, а расположение карточек в списке не меняется.
4. При успешном завершении перетаскивания новый порядок сохраняется так же, как и раньше, без повторных запросов и без изменения поведения для свёрнутых карточек.
5. Свайп по списку вне ручки перетаскивания по-прежнему прокручивает страницу, а перетаскивание мышью и кнопки перемещения вверх/вниз работают без регрессий.
6. Все существующие и новые автоматизированные тесты проходят успешно.

## Task Description

### Контекст и проблема

В рамках задачи WISHENKA-109 было реализовано перетаскивание карточек желаний на сенсорных экранах с помощью ручки перетаскивания. Для раскрытой карточки было принято решение скрывать блок подробностей на время активного жеста перетаскивания. В результате в момент начала жеста карточка резко уменьшается по высоте, а все карточки ниже неё прыгают вверх под пальцем пользователя.

### Выбранный UX-подход

Из трёх рассмотренных вариантов (анимация сворачивания, сохранение приглушённых подробностей, заглушка исходной высоты) выбран вариант **сохранения подробностей в приглушённом виде на время перетаскивания**:

- **Почему не анимация сворачивания:** плавное уменьшение высоты всё равно сдвигает карточки под пальцем пользователя, лишь растягивая смещение во времени, что не решает проблему предсказуемости целевой позиции.
- **Почему не пустая заглушка:** скрытие подробностей с оставлением пустого места под карточкой создаёт неестественный визуальный разрыв и резкую смену формы самой карточки в момент захвата.
- **Почему приглушённые подробности:** карточка сохраняет свою естественную форму и высоту, список под ней не сдвигается ни на пиксель ни при старте жеста, ни при его отмене, а визуальное приглушение всей перетаскиваемой карточки чётко отделяет её от неподвижных целевых карточек.

### Границы задачи (Scope)

- **Входит в задачу:**
  - Устранение скрытия подробностей раскрытой карточки во время touch-перетаскивания с сохранением визуального выделения перетаскиваемой карточки (приглушение, тень, следование за пальцем).
  - Обновление и добавление проверок, подтверждающих отсутствие скачка (сохранение видимости/высоты подробностей при перетаскивании).
- **Не входит в задачу:**
  - Изменение серверной логики сохранения порядка.
  - Изменение поведения перетаскивания мышью или кнопками вверх/вниз.
  - Изменение поведения сворачивания/раскрытия карточек после успешного сохранения порядка на сервере.
  - Ручная проверка на реальных устройствах по общему чек-листу touch-reorder (покрывается отдельной задачей WISHENKA-143).

### Язык реализации

- JavaScript (клиентская логика и стили интерфейса), Python (автоматизированные тесты).

### Основные сущности

- **Карточка желания (раскрытая / свёрнутая)** — элемент списка желаний, имеющий заголовок с ручкой перетаскивания и опционально видимый блок подробностей.
- **Список желаний** — упорядоченный перечень карточек владельца.
- **Жест перетаскивания** — последовательность касания ручки, перемещения карточки над списком и отпускания либо отмены.

## Q&A

- **Q: Нужно ли ждать завершения ручного тестирования на устройствах (WISHENKA-143) перед выполнением этой задачи?**
  A: Нет, в рамках автономного выполнения принято решение реализовать наиболее безопасный и предсказуемый UX-вариант (приглушение подробностей без изменения высоты карточки), который полностью устраняет проблему скачка списка и не ухудшает сценарий со свёрнутыми карточками.
- **Q: Меняется ли состояние раскрытия карточки после успешного сохранения нового порядка?**
  A: Нет, после сохранения нового порядка на сервере список перерисовывается в стандартном свёрнутом виде, как это уже работает для перетаскивания мышью и кнопок перемещения вверх/вниз.
