# AGENTS.md

## Jira

Ключ проекта в Jira: **WISHENKA**.

Задачи, ссылки и поиск относятся к этому проекту (например, `WISHENKA-1`).

### Доска и спринты
- Доска: **WISHENKA board** (Board ID: `199`)
- Поле спринта: `customfield_10020`

### Типы задач (Issue Types)
В проекте WISHENKA (team-managed) настроены следующие типы задач:
- **Epic** — крупные тематические блоки / функциональные направления (уровень иерархии 1). Для них Story Points не выставляются.
- **Story** — основной тип задач реализации и декомпозиции (уровень иерархии 0). Привязываются к родительскому эпику через поле `parent: {"key": "WISHENKA-<N>"}`.
- **Debt** — задачи технического долга (уровень иерархии 0). Используются для фиксации технического долга (в том числе скиллом `tech-debt-jira-sync` на Шаге 7 Top-Down workflow).
- **Bug** — дефекты и баги.
- **Важно:** системный тип `Task` в проекте **не поддерживается** (API возвращает ошибку `Specify a valid issue type`). Все рабочие задачи разработки создаются с типом **`Story`** (или **`Debt`** для техдолга).

### Оценка сложности (Story Points)
- Поле для Story Points: `customfield_10016` (`Story point estimate`). Оценка в шкале Фибоначчи (1, 2, 3, 5, 8, 13).

### Доступные переходы статусов (Transitions)
- `11` — **To Do**
- `21` — **In Progress**
- `31` — **Done**
